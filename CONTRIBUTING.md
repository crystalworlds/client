# Contributing to CrystalWorlds.Media

Suggestions and submissions are welcome from anyone. Every one is read and
considered, whether it is a one-line typo fix or a new piece of hardware
research.

## What you can send

- **Bug reports.** Something that does not work, looks wrong or reads wrong on
  any page, on any screen: desk, phone, fold or TV.
- **A game that does not play right.** Tell us the system, the game's full
  name and region, what you expected and what happened. Please do not attach
  the game.
- **Corrections to a Hardware or Emulation page.** If a page says something
  that is not true of the real machine, show us where and why.
- **Measurements from real hardware.** Timing, sound, colours, button
  behaviour: anything you measured on a real console, with how you measured it.
- **Fixes.** A pull request that fixes a fault, with a short note on what it
  changes and how you checked it.
- **Ideas.** A feature, a better way to show something, a system you would
  like to see.

## How to send it

- **Issues** are for reports, corrections, measurements and ideas. One topic
  per issue, please.
- **Pull requests** are for changes to the code or the pages. Keep each one to
  a single change so it can be reviewed on its own.
- Screenshots and short screen recordings help a lot.

## What is never accepted

**Games and firmware are never accepted.** An issue or pull request that
contains, attaches or links to any of the following is always rejected and
closed, whatever else it contains:

- a game, in any form (a cartridge, disk or tape image, a patched or
  pre-patched copy, an archive that holds one);
- a BIOS, a boot program or any other console firmware;
- a link to where any of these can be downloaded.

This project plays only the files each visitor already owns, and it never
ships, hosts or shares them.
